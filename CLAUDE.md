# Level-Up Plugin

Personal Claude Code coach that assesses your setup and teaches through your real work.

## Commands

- `/level-up` — Get your next highest-impact lesson (or first-run assessment)
- `/level-up --status` — Dashboard of all concepts with maturity levels
- `/level-up --assess` — Full audit of your Claude Code setup
- `/level-up --topic [name]` — Lesson on a specific concept
- `/level-up --refresh` — Update knowledge base with new Claude Code features

## Agents

- **coach** — Personal Claude Code coach for progressive skill-building. Teaches through real tasks, not tutorials.
