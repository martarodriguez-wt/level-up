## Why This Matters for Your Work

If you have multiple agents, some may overlap (do two agents give you substantially the same feedback?), some may be undertuned (generic prompts that don't leverage your domain), and some may be unused. An audit sharpens each agent's unique value and removes noise.

## What You'll Build

An optimized agent roster where every agent has a distinct, non-overlapping perspective. We'll test by running a real document through multiple agents and comparing outputs for redundancy.

## Do This Now

1. **I'll read all your agent files** and create a comparison matrix: what each agent focuses on, what tools it has, what model it uses, and where responsibilities overlap.

2. **We'll test with a real artifact.** Pick a recent document you'd normally want reviewed. I'll run it through 3-4 agents that seem likely to overlap and we'll compare outputs.

3. **Decide and refine.** For overlapping agents: merge, differentiate, or retire. For undertuned agents: add domain-specific instructions relevant to your actual work.

4. **Verify.** Run the same document through the refined agents. Outputs should be distinctly different and complementary.

## You'll Know It Worked When

Each agent produces feedback that no other agent would give. No two agents say the same thing in different words.

## What Just Happened

Agent design is prompt engineering. The best agents have: (1) a clear, narrow mandate, (2) domain-specific knowledge baked in, (3) a distinct communication style, and (4) explicit instructions about what NOT to cover (so they don't overlap). This audit process — test with real input, compare outputs, tighten prompts — is how you maintain agent quality over time. Run it quarterly.
