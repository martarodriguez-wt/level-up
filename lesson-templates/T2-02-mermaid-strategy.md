## Why This Matters for Your Work

Complex systems — workflows, data pipelines, decision trees, org structures — are hard to communicate in text alone. A Mermaid diagram makes relationships visible in a way that paragraphs cannot. And because Mermaid is plain text, it lives inside the markdown file itself — no external tool, no broken image links, version-controllable.

## What You'll Build

A Mermaid diagram embedded in one of your existing documents. We'll pick the document where a visual would add the most value — a workflow, architecture, or decision flow.

## Do This Now

1. **Pick a document.** Which of your files would benefit most from a visual diagram? A strategy doc with interconnected concepts, a workflow with multiple stages, or a system with feedback loops.

2. **I'll draft a Mermaid diagram** that captures the key relationships. You review for accuracy.

3. **I'll embed it** in the document at the right location. Mermaid diagrams render in GitHub, VS Code (with extension), and most markdown viewers.

4. **Iterate conversationally.** "Add a node for X" or "Change the arrow from A to B to dashed" — Claude can edit Mermaid diagrams as easily as text.

## You'll Know It Worked When

Open the document and see a rendered diagram showing how the key concepts connect. Someone unfamiliar with the doc could grasp the structure in 10 seconds.

## What Just Happened

Mermaid is a text-based diagramming language that renders inside markdown. Claude Code can generate and edit Mermaid diagrams conversationally. Supported types: flowcharts, sequence diagrams, class diagrams, state diagrams, Gantt charts, pie charts, ER diagrams, and more. Use it for: user flows, system architecture, decision trees, data pipelines, org charts, timelines.
